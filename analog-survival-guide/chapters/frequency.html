Av,dB = 20lg|Av|
BW = fH − fL ≈ fH（当 fH ≫ fL）
截止频率处：|Av| = |Avm| / √2

速通

01 · 中频区

先找最平的那一段

平台段 = 中频区；中频增益就是整张图的基准。

02 · 截止频率

盯住 −3 dB

中频增益下降 3 dB 的两点，就是 fL、fH。

03 · 通频带

BW = fH − fL

BW=fH−fL；若 fH≫fL，常近似 BW≈fH。

04 · 低频端

先看耦合电容 / 旁路电容

频率降低时容抗增大，信号传输或旁路作用变弱，低频增益下降。

05 · 高频端

先看结电容 / 极间电容

高频时器件内部与极间电容效应增强，决定上限截止频率附近的衰减和附加相移。

06 · 失真判断

先看每个频率是否都落在通带里

逐个频率和通带比；有分量出带，就警惕线性失真。

低频端主要受耦合、旁路电容影响，高频端主要受晶体管内部电容影响；中间平台就是中频区。

BW = fH − fL
截止点：|Au| 降到中频值的 0.707 倍，即 −3 dB
做题时：先在图上标 fL、fH，再判断给定频率落在哪一段。

给频率特性表达式时，先拆低频因子和高频因子

这类题通常不是硬算复数，而是从每个一阶因子里读出截止频率，再取主导极点或组合判断。

±3 dB 常考：不同频率要分别判断所在频段。若再叠加负反馈，通常 fH ↑、fL ↓，通频带会变宽。

知识点详解

01｜这一章必须会的概念

这章先把八个词连成一张图：幅频响应、相频响应、线性失真、中频增益、上限截止频率、下限截止频率、通频带、增益频带积。

真正要练的是：看到图或频率特性表达式，能立刻认出中频区、截止点和相位信息，再进入计算。

02｜中频区：整张频响图的基准

中频段通常作为增益近似稳定的基准区。很多题先给中频增益，再让你判断某个低频或高频信号相对它衰减了多少。

因此读频响图时，第一步通常不是找截止频率，而是先把中频平台认出来。

03｜低频端与高频端不要混

阻容耦合放大器中，影响上限频率的重要因素是晶体管级间电容。

所以先判断题目研究的是低频端还是高频端，再决定应该关注耦合/旁路电容，还是器件内部高频电容效应。两边的物理原因不要混着解释。

04｜截止频率与 ±3 dB

截止频率和 ±3 dB 要绑在一起理解。题目给出两个不同频率的信号时，先判它们落在低频、中频还是高频区，再比较相对中频增益的衰减。

另一类典型题是直接给频率特性表达式，让你从式子中读出中频电压增益和截止频率。

05｜相频响应

频率响应不只有“幅值掉了多少”，还要看相位。课程压缩笔记明确记了一条：单管共射电路在上限频率处，输出电压相对输入再滞后 45°。

这一句按课程笔记的考试口径保留。若具体题给出完整传递函数或另行规定相位参考，则按题目定义处理，不机械套用。

06｜增益频带积：会认概念，不硬补公式

“增益频带积”被课程总结明确列进本章考点，但现有笔记文本没有继续展开它的公式推导。

因此这里把它保留为必须认识的概念：若题目给出定义、频响表达式或具体关系，就按题设使用；网页不额外编一套笔记里没有展开的推导。

07｜和反馈章节联动

反馈章节会再次把频响拿出来考：负反馈会使上限截止频率增大、下限截止频率减小，从而展宽通频带。

所以频率响应并不是孤立的一章，选择填空里很可能和反馈性能改善一起出现。

历年真题

四套卷里，频率响应只有 2019–2020 出过独立大题；其余年份主要散在选择填空里，所以这章更适合做“概念速通 + 一道母题”。

Exam Coverage四套卷里只有 1 年出现独立频率响应大题，但笔记把概念、±3 dB、上下限截止频率和增益频带积都列为考点；“结间电容影响上限频率”“fH 处共射输出滞后 45°”也值得直接记。

2019–2020 B卷 · 第4题

幅频特性中频增益fL / fHBW线性失真
6 分 · 母题
FIRST LOOK

先读平台，再找两个 −3 dB 点

判断

这题不需要回到电路：先从幅频图读中频增益、f_L、f_H，再判断各频率分量是否落在通带内。

步骤
读平台 → 找 −3 dB 点 → 得 f_L、f_H → 求 BW → 判断频率分量
易错
dB 和倍数别混；这里考的是频率特性造成的线性失真。
得分提醒把“中频平台 → 两个 −3 dB 点 → fL/fH → BW”按顺序写，读图题最怕直接跳到带宽。
关键结果

中频增益约 40 dB = 100 倍；fL≈10 Hz，fH≈106 Hz，因此 BW≈106 Hz。

输入中 104 Hz 分量位于通带内，而 108 Hz 明显高于 fH，所以输出发生高频线性失真。

其他三年怎么考？

2018–2019、2020–2021、2021–2022 都没有独立频响大题，但在选择填空中会继续考：截止频率、阻容耦合高频限制、共射相位、以及频率响应相关概念。这个模块题量不大，但属于很适合考前快速拿分的一章。

2026 模拟测验 · 选择填空第11题

传输函数中频增益上限截止频率−3 dB附加相移
5 个空 · 高频概念
2026 MOCK

给 A(jω) 时，先标准化成“一阶低通”再读参数

得分链提出常数项 → 读 Aum → 20lg|Aum| → 读 ωH 并换算 fH → 截止点减 3 dB、附加相移 −45°
易错题目问的是“附加相移”时，不要把共射本身的 180° 反相一起混进去。
结果 / 口径

该模拟题 A(jω)=1000/(10+jω/10000)：中频增益 40 dB，fH≈15.9 kHz，截止点实际增益约 37 dB，附加相移约 −45°。
