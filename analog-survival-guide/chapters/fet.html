Core Formula
UGS = UG − US
ID = IDSS(1 − UGS/UGS(off))²
gm = Δid / Δugs
共源基本型：Au ≈ −gmR′L
JFET 自偏置时，常见 UG≈0，因此可直接写成 UGS=−IDRS。先把静态关系立起来，再决定后面用解析法还是图解法。

核心笔记

DIAGRAM · TYPE ID

看 uGS 的取值范围，先把管型认出来

快速判断可以先看：uGS 有正有负 → 耗尽型 MOSFET；全为正 → 增强型 MOSFET；全为负 → JFET。先认管型，再看沟道方向和转移特性。

IDSS：转移曲线与 iD 轴交点
UGS(th) / UGS(off)：看 uGS 轴交点
做题时：认管型题别先死背符号，先看 uGS 能落在哪一段。
METHOD · BIAS

偏置先问：这个管能不能自偏？

JFET、耗尽型 MOSFET 可用自给偏置；增强型 MOSFET 需要 uGS>0 才形成沟道，因此增强型 MOSFET 不用这套自给偏置。分压偏置可用于各种 FET。

IG ≈ 0
典型 N 沟道 JFET 自偏：UGS = −IDRS
算 Q 点：求 UG → 写 UGS → 代恒流区公式 → 求 UDS → 验工作区。

小信号模型：gmuGS 是主角，rds 别凭空删

低频小信号模型里，受控电流源为 gmuGS，rds 接在漏源之间。通常可以先把 rds 看成开路；若题目给出 λ 或 rds，就应保留。

交流通路：耦合 / 旁路电容按交流短路处理
共源 Au 常带负号；Ri、Ro 从等效图直接看
做题顺序：画交流通路 → 换小信号模型 → 再列 Au / Ri / Ro。

源极电阻和级间负载：先画交流通路

RS 未被旁路时会形成局部负反馈，增益下降但稳定性更好；多级放大时，后一级输入电阻还会并入前一级负载。

RS 是否参与交流 → 先看旁路电容
前一级有效负载：RD ∥ RL ∥ Rin,next
做题时：交流通路先画对，后面的 Au / Ri / Ro 才不会乱。

知识点详解

01｜JFET：uGS 控沟道，uDS 推工作区

JFET 的原理可以按两个控制变量来理解：先固定 uDS，看 uGS怎样改变沟道宽度；再固定 uGS，看 uDS怎样把器件从未夹断推到预夹断，最后进入恒流区。

N 沟道 JFET 正常工作时要保证栅源 PN 结反偏，可直接记成 uGS<0；P 沟道方向相反。

02｜增强型 / 耗尽型 MOSFET

增强型 MOSFET 的第一道门槛是让 uGS 超过开启电压 UGS(th)：先形成反型层和导电沟道，后面才谈得上漏极电流与工作区；耗尽型 MOSFET 则可以和 JFET 放在一起类比。

因此增强型 MOSFET 不适合自给偏置：还没有足够的 uGS时，就没有漏极电流去建立所需的源极电压。

03｜看曲线认管型

看转移特性认管型时，先看 uGS 的取值范围：有正有负，多半对应耗尽型 MOSFET；全为正，对应增强型 MOSFET；全为负，对应 JFET。

图上与纵轴的关键交点对应饱和漏极电流，与横轴的关键交点对应夹断电压或开启电压。先认管型，再读参数，顺序不要反。P 沟道图形可以先与 N 沟道作镜像类比，再结合电压、电流方向判断。

04｜自偏置与分压偏置

自偏置常用于 JFET、耗尽型 MOSFET；分压偏置适用于各种 FET。因为 FET 输入电阻很大，分析栅极网络时通常先用 IG≈0 简化。

自偏置最常用的电路关系仍是 UGS=UG−US。先把这条电路关系写清楚，再和器件恒流区公式联立。

05｜静态 Q 点：解析法 + 图解法

两种方法都要会。解析法是把偏置关系和器件方程联立；图解法则是把电路给出的偏置线画到转移特性上，交点就是 Q 点。

如果方程给出多个数学根，要根据器件工作条件筛掉不合理的根；如果使用了恒流区公式，最后还要反过来校验求出的 Q 点确实落在该工作区。

06｜低频小信号模型

FET 小信号模型是本章核心。动态分析固定成两步：先处理耦合电容、旁路电容和交流地，再把器件替换成 gmugs 受控源与 rds。

不少基础题会按题意把 rds近似开路处理，但是否忽略要看题目条件，不要形成机械习惯。

07｜共源：最常见动态题

共源题最容易因为源极电阻是否被旁路而分成两套。RS被旁路时更接近标准共源；没有旁路时，RS会进入交流关系，增益表达式也随之变化。

做题固定成一条链：交流通路 → 小信号模型 → Au / Ri / Ro。先画对，再算。

08｜共漏：重点看等效通路和 Ro

共漏放大尤其要会画求输出电阻时的等效通路。它虽然有“电压跟随”的直观特征，但考试真正容易卡住的仍然是交流网络怎么画。

尤其在求 Ro时，先按题目要求把独立源置零，再从输出端看进去，不要只凭结构印象写结论。

2018–2019 A卷 · 第4题

JFET自偏置Q 点恒流区小信号
8 分 · 母题
FIRST LOOK

JFET 自偏置：第一行先立关系

判断

I_G≈0，因此先写 U_G≈0，再由源极压降得到 U_GS=−I_D R_S；静态关系立住后再解 Q 点。

步骤
U_G≈0 → U_GS=−I_D R_S → 联立器件方程 → 筛根 → 校验工作区
易错
有多个数学根时，只保留满足器件工作条件的物理解。
得分提醒第一问把 UGS=−IDRS 单独写清楚。后面的最小电源电压和小信号参数都依赖这个 Q 点。
关键结果

IDQ≈0.764 mA，最小 UDD≈6.6 V。

2019–2020 B卷 · 第8题

JFET自偏置Q 点小信号
6 分 · 迁移题
FIRST LOOK

换数字，不换母题

判断

仍是 JFET 自偏置：偏置关系和器件方程联立即可，后续再校验工作区。

步骤
U_GS=−I_D R_S → 联立器件方程 → 求 Q 点 → 校验

2020–2021 A卷 · 第6题

共源小信号AuRiRo
10 分 · 动态主线
FIRST LOOK

先看旁路电容，再画交流通路

判断

C3 对交流近似短路，源极交流接地，因此按标准共源小信号模型处理。

步骤
处理电容 → 画交流通路 → 求 A_u → 求 R_i → 求 R_o
易错
求 R_o 时去掉外接负载；求 R_i 时别漏偏置网络。
得分提醒先在交流通路上明确“哪些电容视为短路、RS 是否被旁路”，再写 Au；这一步写清楚最容易保住过程分。
关键结果

Au≈−49.5，Ri≈1.0375 MΩ，Ro≈10 kΩ。

2021–2022 B卷 · 第2题

图解法Q 点共源AuRiRo
10 分 · 综合验收
FIRST LOOK

图解 Q 点：两条关系找交点

判断

转移特性给器件关系，U_GS=−I_D R_S 给外部偏置关系，两者交点就是 Q 点。

步骤
写偏置直线 → 读交点 Q → 处理旁路 → 小信号分析
易错
图解法也要先写出外部电路约束，不能只凭目测。
得分提醒图解题最好把偏置直线与转移曲线的交点先标出来，再读 IDQ、UGSQ，单位别丢。
关键结果

IDQ≈3 mA，UGSQ≈−1 V；Au≈−7.8，Ri≈1 MΩ，Ro≈8.2 kΩ。

2026 模拟测验 · 第5题

JFETQ 点双电源源极电阻改进设计
12 分 · 新母题
2026 MOCK

先求 Q 点，再判断源极电阻对交流增益的影响

得分链写 Shockley 方程 → 写 UGSQ 的电路关系 → 联立求 IDQ / UGSQ → 求 UDSQ → 检查 RS 对交流的负反馈
易错“提高交流增益”不是把 RS 在直流上直接删掉；更稳的做法是在 RS 上并联旁路电容，使其交流近似短路，同时保留直流自偏置。
结果 / 口径

模拟测验给出的 Q 点结果为 UGSQ≈−0.96 V、IDQ≈3.24 mA、UDSQ≈7.8 V。
