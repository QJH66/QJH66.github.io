核心笔记

这一章先抓三件事：Q 点怎么动、失真怎么判、最大不失真摆幅怎么算。图留着，旁边只放做题真正会用到的东西。

复习顺序先 Q 点 → 再小信号 → 再三种组态 → 最后失真 / 最大摆幅卡住时先把直流负载线和交流等效图画出来。
DIAGRAM · Q POINT

RB、RC 改变时，Q 点到底怎么走？

改 RB：直流负载线不变，变化的是 IBQ，所以工作点沿原直流负载线移动。

改 RC：IBQ 不变，但直流负载线斜率改变，因此 Q 点沿对应输出特性曲线移动。

uCE = VCC − iCRC
直流负载线斜率 ∝ −1 / RC
做题时：不要背“左移右移”，先问自己：这次是换 IB 曲线，还是换负载线？图就不会乱。
EASY TO MISS · DISTORTION

截止 / 饱和失真：先看 Q 点离哪一端更近

这里直接记：Q 点过低，更容易碰到截止端；Q 点过高，更容易碰到饱和端。输入增大后，离 Q 点更近的一侧先被“顶住”，于是输出出现削顶。

对 NPN 共射题，原图还把输出削顶方向画了出来。考场上结合相位反转和 Q 点位置一起判断，比单背波形更稳。

怎么改：先考虑减小输入幅值；若题目要求调偏置，就把 Q 点往更合适的动态范围中部移动。

共射、共集、共基，别混着背

三种组态最容易一起考。先抓用途，再补相位和阻抗，比背一整张表稳。

共射电压放大能力强输入 / 输出反相最常见的电压放大
共集Au ≈ 1输入电阻大、输出电阻小电压跟随，带负载强
共基有电压放大，无电流放大输入 / 输出同相频带宽，适合高频
记法：共射看“放大”，共集看“跟随 / 带负载”，共基看“高频”。

最大不失真摆幅：限制你的是更近的那一端

交流负载线经过静态工作点 Q。向饱和端和截止端分别还能摆多少，两个余量都算出来，最后取较小者。

交流负载线：经过 Q，斜率 = −1 / R′L
UR = UCEQ − UCES
UF = ICQR′L
Uom,max = min(UR, UF)
看到这类题：出现“最大不失真输出 / 动态范围 / 交流负载线”，先找 Q 点到两端的余量。

知识点详解

01｜认管型、认电极、判状态

先把最基础的判断做熟：看三个电极电位，确定 b / e / c，再判断 NPN 或 PNP，最后判断管子处在放大、饱和、截止还是异常状态。这几步看起来零碎，但后面的静态分析都建立在这里。

状态判断主线很清楚：放大区——发射结正偏、集电结反偏；饱和区——两个结都正偏；截止区——发射结没有正向导通。

02｜三种偏置电路与 Q 点

“三种偏置电路求 Q 点”是这一章的静态分析主线，课程范围也基本围绕这套偏置结构展开。静态题不要急着套公式，先画直流通路，再沿偏置网络一步步求 IBQ、ICQ、UCEQ。

静态看直流通路，动态看交流通路。电容在两种分析里处理不同，这是整章最容易因为“顺手”而出错的地方。
03｜Q 点、直流负载线与参数变化

改变 RB 时，直流负载线本身不动，变的是基极电流，所以 Q 点沿负载线移动；改变 RC 时，直流负载线斜率改变，而原来的 IBQ 不变，因此 Q 点沿对应输出特性曲线移动。

交流负载线只抓两件事：斜率由交流负载决定，而且一定经过静态工作点 Q。画图题先把这两个约束钉住，后面就不容易乱。

04｜截止失真、饱和失真与动态范围

判断失真不要只认波形名称。先看 Q 点离截止端、饱和端哪一侧更近，再判断哪一侧先被“顶住”；选择填空经常就从这里出。

处理思路只有两类：减小输入幅值，或调整偏置让 Q 点回到更合适的位置。笔记中还专门写了饱和侧允许摆幅 U_R=U_{CEQ}-U_{CES}；完整最大不失真幅值仍要同时受截止、饱和两侧限制。

05｜共射：动态大题主线

共射是 BJT 动态大题最常见的主线。固定顺序：画交流通路 → 画小信号等效模型 → 求 Au、Ri、Ro；题目再往前一步时，补求源电压增益 Aus。

“发射极有 RE 且旁路电容消失”是很典型的变式。此时交流通路已经变了，不能继续照搬完全旁路时的公式。

06｜共集：电压跟随器

共集可以压成一句话：Au≈1、输入输出同向、Ri大、Ro小——典型的电压跟随与缓冲结构。

求输出电阻时要特别小心。信号源内阻不能随手丢掉，因为它会进入 Ro 的计算。

07｜共基：宽频带

共基有电压放大能力，输入输出同向，但没有电流放大作用；三种基本接法中，它的频带最宽。

共基与共射的直流通路相同，因此 Q 点相同。真正需要重新处理的是交流输入端、输出端以及对应的小信号通路。

08｜Ri、Ro 与多级负载

Ri可以理解为“从信号源获得信号的能力”，Ro则对应“带负载能力”。这两个量不只是公式题，常常直接决定电路为什么选某一种组态。

多级放大时，后一级对前一级就是负载，可以用后一级输入电阻等效。所以总增益不能把每一级孤立算完后简单相乘，级间负载必须带进去。

09｜综合变式：稳压管、无隔直电容、多级

本章还有几个“看起来不像标准题”的常见变化：输出端没有隔直电容、和稳压管结合、多级放大。它们真正变化的不是公式数量，而是直流通路或交流通路。

碰到陌生结构，先重新画通路，再判断原来的公式哪些还能用。这个习惯比记更多变式更稳。

历年真题

这三道题刚好覆盖：解析法 Q 点、图解负载线、动态参数。

Exam Coverage四套卷里有 3 年出现独立 BJT 大题。大题主线是 Q 点、负载线和动态参数；另外共集 / 共基特点、动态范围与失真在笔记里被反复标成易考选填。

2018–2019 A卷 · 第2题

共射分压偏置Q 点RiRoAu
10 分 · 母题
FIRST LOOK

直流定 Q，交流再算动态

判断

先用分压偏置求静态工作点；进入交流分析后重新画通路，再算 r_be、R_i、R_o、A_u。

步骤
求 U_BQ → 求 I_CQ、U_CEQ → 算 r_be → 交流等效 → 动态参数
易错
发射极电阻未被旁路时，交流增益里不能直接删掉 R_E。
得分提醒直流通路和交流通路分开写，先定 Q 点再算 Au/Ri/Ro，不要把两套等效图混在一起。
关键结果

UBQ≈2.0 V，IBQ≈10 μA，ICQ≈0.49 mA（约 0.5 mA），UCEQ≈5.7 V；rbe≈2.65 kΩ，Ri'≈135.25 kΩ，Ro≈10 kΩ，Au≈−1.85。

2019–2020 B卷 · 第2题

输出特性直流负载线交流负载线失真Q 点
14 分 · 图解主线
FIRST LOOK

主线只有一条：偏置 → Q 点 → 动态范围

判断

先由偏置得到 I_BQ，再在输出特性上确定 Q 点；直流/交流负载线和失真判断都围绕 Q 点展开。

步骤
算 I_BQ → 画直流负载线 → 定 Q → 画交流负载线 → 判失真
易错
别只会“读图”，要能说清 Q 点为什么这样移动。
得分提醒两条负载线都要经过 Q 点；交流负载线的斜率用“交流负载”，这是最常见的失分点。
关键结果

IBQ≈20 μA，ICQ≈2 mA，UCEQ≈3 V。 随输入正弦幅度逐渐增大时，原卷解答判断先出现截止失真；若希望获得更大的不失真输出，应减小 Rb，使 Q 点向上移动。

2020–2021 A卷 · 第3题

βQ 点负载线AuRi
14 分 · 综合题
FIRST LOOK

先读 β，再做完整共射分析

判断

题目把特性图与共射放大合在一起：先读 β，再求 Q 点，最后进入交流负载线和小信号参数。

步骤
读 β → 求 Q → 画负载线 → 算 r_be → 求 A_u、R_i
易错
读出 β 只是第一步，后面的直流/交流分析仍要分开。
得分提醒题目若从输出特性给 β，就先读图求 β，再进入共射分析；不要默认 β=100。
关键结果

β≈100，IBQ≈30 μA，ICQ≈3 mA，UCEQ≈6 V；RC∥RL=1.5 kΩ，rbe≈875.3 Ω，Au≈−171.37。
