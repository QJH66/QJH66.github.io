核心笔记

反馈别一次猜全名。先找通路，再判正负，再拆“输出取样”和“输入混合”。

四种反馈组态：拆成两个判断

输出端判断电压 / 电流反馈；输入端判断串联 / 并联。复杂图也只是在重复这两步。

输出短路后反馈消失 → 电压反馈
输入量与反馈量落在同一点 → 并联；否则 → 串联
顺序：找反馈通路 → 判正负 → 判电压 / 电流 → 判串 / 并。

深反馈：先把输入量和反馈量近似起来

串联混合看电压，并联混合看电流。AF 足够大时，闭环增益主要由反馈网络决定。

串联：Ui ≈ Uf　｜　并联：Ii ≈ If
Af = A/(1+AF)　｜　AF ≫ 1 ⇒ Af ≈ 1/F
串联反馈 → Rif ↑　｜　并联反馈 → Rif ↓
电压反馈 → Rof ↓　｜　电流反馈 → Rof ↑

题目给“要求”，就反推反馈组态

想稳定输出电压，就先选电压反馈；想稳定输出电流，就先选电流反馈。再看输入端希望高阻还是低阻，决定串联还是并联。

两个问题就够：输出想稳什么？输入想要高阻还是低阻？

知识点详解

01｜反馈到底是什么

反馈不是“看到一根线从后面绕回来”这么简单。它的关键定义是：把输出量的一部分或全部回送到输入回路，并且真的影响输入量。

所以判断有没有反馈，先找输出回路和输入回路之间的联系，再检查这条联系是否真正改变了输入。

02｜基本方程与反馈深度

用 A 表示开环增益、F 表示反馈系数、Af表示闭环增益，并用 D=1+AF 表示反馈深度。

Af = A / (1 + AF)

当反馈足够深时，核心近似就是 Af≈1/F。大题里一旦明确进入深反馈，后面的计算会明显简化。

03｜正反馈 / 负反馈：瞬时极性法

从输入端给一个瞬时变化，一路追到输出，再沿反馈通路回到输入端，看反馈量让净输入变大还是变小。

净输入减小 → 负反馈；净输入增大 → 正反馈。关键是顺着信号传递方向一步步标极性，不要凭电路“长相”判断。

04｜电压反馈 / 电流反馈：输出短路法

判断电压 / 电流反馈时采用输出负载短路法：把输出端短路后，反馈消失 → 电压反馈；反馈仍存在 → 电流反馈。

功能上也可以反过来检查：稳定输出电压，用电压负反馈；稳定输出电流，用电流负反馈。

05｜串联反馈 / 并联反馈：看输入端点

输入端点与反馈端点不在同一点 → 串联反馈；落在同一点 → 并联反馈。这是最快的一条判断法。

完整组态判断建议固定成三步：先判正负，再判电压/电流，最后判串联/并联。顺序固定以后，复杂多级电路也不会乱。

06｜深反馈大题

大题套路基本不变：找反馈通路 → 判反馈类型 → 写反馈关系 → 在深反馈条件下求 Af，必要时继续求 Rif、Rof。

多级电路只是图更长，分析核心没有变化。先抓反馈网络，别先陷进每一级晶体管的细节。

07｜负反馈对性能的影响

负反馈对性能的影响最好成组记：增益更稳定、通频带更宽、非线性失真更小、反馈环内干扰和噪声更小，同时改变输入/输出电阻。

几个倍数关系属于高频考点：非线性失真约减小为原来的 1/(1+AF)，通频带大致按反馈深度展宽；串联反馈使输入电阻增大，并联反馈使输入电阻减小；电压反馈使输出电阻减小，电流反馈使输出电阻增大。

08｜按题意选择反馈

这部分最适合“按目标反推”：稳定输出电压 → 电压反馈；稳定输出电流 → 电流反馈；提高输入电阻 → 串联；降低输入电阻 → 并联；增强带负载能力 → 优先电压反馈；希望接近恒流源输出 → 优先电流反馈。

信号源侧还可以这样快速选：恒压源配串联反馈，恒流源配并联反馈。压缩笔记还特别提醒反馈效果与信号源内阻有关：串联反馈希望 Rs 较小，并联反馈希望 Rs 较大；反过来时反馈效果会明显变弱。

09｜自激振荡

负反馈放大器在高频或低频段可能因为电抗元件影响而产生自激：即使输入为 0，输出仍在某一频率上出现交流信号。

这部分不要和后面“正弦波振荡器主动引入正反馈”混在一起。一个是负反馈系统失去稳定性，一个是专门设计振荡。

历年真题

四年连续出现大题，主线非常稳定：反馈组态判断 + 深负反馈增益 + Ri / Ro 变化。

Exam Coverage四套卷里 4/4 都有反馈题，而且笔记明确写了“反馈相关选择填空必出”。除了组态和深反馈，稳定性、带宽、失真、Ri/Ro 的变化也要成组记忆。

2018–2019 A卷 · 第6题

多级放大电压并联负反馈深反馈闭环增益
10 分 · 母题
FIRST LOOK

给 R_i、R_o 变化：直接倒推反馈组态

判断

输入电阻要减小 → 并联反馈；输出电阻要减小 → 电压反馈，所以目标是电压并联负反馈。

步骤
由 R_i/R_o 倒推组态 → 接反馈支路 → 判负反馈 → 深反馈求闭环增益
易错
先分“输入串/并”和“输出电压/电流”，不要凭感觉认组态。
得分提醒若题目直接给 Ri/Ro 的变化，可以反推串/并与电压/电流反馈；把判断依据写出来比只写四字组态更稳。
关键结果

卷面解答：反馈类型为电压并联负反馈；深负反馈条件下，Auf=Uo/Us≈−Rf/Rb。

2019–2020 B卷 · 第6题

共射共集电压并联负反馈深反馈
10 分 · 迁移题
FIRST LOOK

先认基本级，再找反馈支路

判断

先认 VT1、VT2 的基本接法，再看输出如何回到输入；卷面对应电压并联负反馈。

步骤
认基本级 → 找反馈通路 → 判电压/电流 → 判串/并 → 深反馈列关系
易错
反馈支路必须真正影响输入，不能只看到“有一根线连回去”。
得分提醒先认清每一级是什么基本放大电路，再找跨级反馈支路；不要被多级结构带着逐级硬算。
关键结果

卷面结果：VT1 为共射，VT2 为共集；反馈为电压并联负反馈；深反馈下 Auf≈−Rf/Rb1。

2020–2021 A卷 · 第7题

理想运放级间反馈电压并联负反馈Rif / Rof
10 分 · 运放变式
FIRST LOOK

器件换成运放，反馈判断逻辑不变

判断

最终输出通过反馈支路回到 A1 的反相输入节点，仍按电压并联负反馈处理，再用理想运放线性关系求闭环。

步骤
找反馈通路 → 判组态 → 用虚短/虚断 → 写闭环关系
易错
先判反馈，再用运放规则；顺序别反。
得分提醒先判反馈组态，再用虚短 / 虚断求闭环。顺序反过来，很容易把反馈支路当普通运放电阻。
关键结果

卷面结果：电压并联负反馈；Auf=−R2/R1=−1；Rif=R1=100 kΩ，Rof=0。

2021–2022 B卷 · 第5题

电压串联负反馈Ri / Ro反馈系数深反馈
10 分 · 综合题
FIRST LOOK

先判组态，再看反馈网络 F

判断

卷面判断为电压串联负反馈；深反馈条件下，闭环增益主要由反馈网络决定。

步骤
判电压串联 → 写 F → 深反馈用 A_uf≈1/F → 再判断 R_i、R_o
易错
反馈组态和“1/F”是两步，别直接跳到公式。
得分提醒深反馈题优先求反馈系数 F，再用 Af≈1/F；不要先花时间求完整开环增益 A。
关键结果

卷面结果：电压串联负反馈；输入电阻增大、输出电阻减小；F=1/91，Auf≈91。

2026 模拟测验 · 第6题

级间反馈反馈组态深负反馈改接设计
12 分 · 设计型母题
2026 MOCK

不仅要会“判型”，还要能按目标指标反推反馈组态

得分链找 R1/Rf 反馈通路 → 判电压串联负反馈 → 深反馈写 Auf≈1/F → 若要求低 Ri 且带负载强，反推为电压并联负反馈
易错“低输入电阻”对应并联混合；“带负载能力强 / 输出电阻低”对应电压取样。不要只背某一种组态名称。
结果 / 口径

模拟测验给出的深反馈口径：Auf=1/F=1+Rf/R1。
